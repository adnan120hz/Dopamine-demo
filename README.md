# Dopamine demo

A userland demo of the Dopamine jailbreak app's interface for iOS 27.0.1 (A13/A15) — no jailbreak, no kernel exploit, no privileges.

This is a demo, not a jailbreak. The kernel code is removed. What runs is the UI, the log, and a respring — nothing more.

## What it is

- The real Dopamine app UI, running on stock iOS 27.0.1
- Shows the jailbreak screen, log output, and respring flow
- Supported iOS 27.0.1 (A13/A15) (userland)

## What it is not

- Not a jailbreak. It cannot jailbreak any device.
- No kernel exploit, no root, no tweak injection.

## Install

Sideload the IPA with your own certificate (AltStore, SideStore, LiveContainer, or similar).
